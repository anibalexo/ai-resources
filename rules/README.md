# Rules

Reusable rules and conventions to guide assistants' work across projects.

## Organization

Group each coherent set of rules in a file or folder. Use Markdown for generic rules and the tool's required format for specific configurations.

## What to document

- Purpose and scope of application.
- Compatible tool and installation location.
- Complete rules and values that need to be adapted.
- Assumptions about the project's language, architecture, or practices.

## Usage

Select the relevant rules, adapt them to the project, and check that they are compatible with its existing instructions before incorporating them.
