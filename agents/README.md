# Agents

Reusable agent definitions and configurations with a specific role, scope, and tools.

## Organization

Use one file per agent, or a folder if it needs several files. Preserve the tool's native format and include a Markdown guide when that format cannot explain usage.

## What to document

- The agent's role, tasks, and boundaries.
- Compatible tool, required model if applicable, and necessary permissions.
- Input context and expected output.
- Configuration, activation, and a usage example.

## Usage

Adapt the definition to the project, review the tools and permissions it needs, and follow its platform's activation instructions.

This folder stores reusable definitions. An `AGENTS.md` file at the root would provide instructions for this repository.
